# Contributing to OreoTunes

Thank you for your interest in contributing to OreoTunes!

OreoTunes is an open-source Android music player built with Kotlin, Jetpack Compose, and Material 3.

## Before contributing

- Check existing issues and pull requests before starting duplicate work.
- Read the Code of Conduct.
- Keep changes focused and easy to review.
- Test your changes before submitting them.
- Do not include private credentials, API keys, or personal information.

## Reporting bugs

Use the Bug Report issue template and include your device model, Android version, OreoTunes version, steps to reproduce, expected behavior, actual behavior, and relevant screenshots or logs.

## Suggesting features

Use the Feature Request issue template and explain what you would like OreoTunes to do, why it would be useful, and how it could work.

## Development

OreoTunes uses Kotlin, Jetpack Compose, Material 3, AndroidX, and Media3.

Release build:

    ./gradlew :app:assembleRelease

Debug build:

    ./gradlew :app:assembleDebug

## Pull requests

Use the pull request template. Explain what changed, why it was needed, how it was tested, and include screenshots for UI changes.

## Code quality

Keep contributions readable, maintainable, focused, and consistent with the existing project architecture.
